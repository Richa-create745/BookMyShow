# 🎬 BookMyShow Clone

A Full Stack Movie Ticket Booking Application

## 📌 About the Project

BookMyShow Clone is a movie ticket booking web application inspired by BookMyShow. It provides a platform where users can explore movies, view available shows, and check seat availability.

This project is developed to demonstrate full-stack web development using Java, Spring Boot, MySQL, and frontend technologies.

## ✨ Features

- 🎥 Browse and explore movies
- 🏙️ City-based movie information
- 🎭 View and manage movie shows
- 💺 Check seat availability for shows
- 🗄️ Store and retrieve data using MySQL
- 🔗 Backend integration using Spring Boot
- 🎨 Interactive user interface

## 🛠️ Technologies Used

- **Java** – Backend programming
- **Spring Boot** – Backend development and REST APIs
- **Spring Data JPA** – Database operations
- **MySQL** – Database management
- **HTML5** – Web page structure
- **CSS3** – Styling and layout
- **JavaScript** – Frontend interactivity
- **Git & GitHub** – Version control

## 🎯 Project Objective

The main objective of this project is to build a movie ticket booking platform while gaining practical experience in backend development, database connectivity, REST APIs, and frontend-backend integration.
